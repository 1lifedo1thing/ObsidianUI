# 404

A page-not-found scene carved into a canvas surface. Move your cursor near the numerals to nudge their edges, or use the links to get back on track. The scene follows your site theme and respects reduced-motion preferences.

## Usage

Add the component to your App Router `not-found.tsx` file. The default buttons lead to your home page and component gallery; change their labels and destinations through props.

```tsx copy
import { FourOhFour } from '@/components/block/404'

export default function NotFound() {
  return (
    <main className="flex min-h-screen items-center justify-center p-6">
      <FourOhFour className="min-h-[520px] max-w-5xl rounded-3xl" />
    </main>
  )
}
```
