# ObsidianUI Developer Portal

Find component source files, installation guides, the public API, and resources for coding agents.

## Build with ObsidianUI

ObsidianUI is an open-source React component library for motion, cursor effects, scroll interactions, backgrounds, and interface details. Use the previews to choose a component, then install its source into your own project.

Each registry item includes its source files, local dependencies, installation targets, and npm dependencies. Review the complete item before writing files so your customizations stay intact.

[Browse components](https://www.obsidianui.dev/components)

[Installation guide](https://www.obsidianui.dev/docs/installation)

[Component registry](https://www.obsidianui.dev/r/registry.json) — Complete machine-readable catalog and component files.
