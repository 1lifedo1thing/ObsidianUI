# ObsidianUI — Install Next.js

[Canonical page](https://www.obsidianui.dev/docs/installation) · [Agent guide](https://www.obsidianui.dev/agent-instructions.md)

Create a new Next.js project with TypeScript, Tailwind CSS, ESLint, and App Router.

***

## Create Project

Run the following command to create a new Next.js project:

```bash
npx create-next-app@latest my-app --typescript --tailwind --eslint --app --src-dir --import-alias '@/*'
```

Navigate to your project directory:

```bash
cd my-app
```
